# GREEN-API Console — Тестовое задание

Тестовое задание на позицию **«Специалист технической поддержки 2 линии»** в компанию **GREEN-API**.

Веб-приложение представляет собой интерактивную панель управления методами GREEN-API, реализованную на чистом HTML, CSS и JavaScript в строгом соответствии с предоставленным макетом.

---

## 🚀 Функционал и реализованные методы

Приложение реализует прямое взаимодействие с REST API сервиса [GREEN-API](https://green-api.com/):

1. **`getSettings`** (`GET {{apiUrl}}/waInstance{{idInstance}}/getSettings/{{apiTokenInstance}}`)
   - Получает текущие настройки инстанса (вебхуки, задержки, параметры фильтрации и т.д.).
2. **`getStateInstance`** (`GET {{apiUrl}}/waInstance{{idInstance}}/getStateInstance/{{apiTokenInstance}}`)
   - Проверяет текущее состояние авторизации инстанса (`authorized`, `notAuthorized`, `blocked`, `starting` и др.).
3. **`sendMessage`** (`POST {{apiUrl}}/waInstance{{idInstance}}/sendMessage/{{apiTokenInstance}}`)
   - Отправляет текстовое сообщение в личный чат (`chatId: 77761985879@c.us`) или групповой чат.
   - Поддерживает автоматическое форматирование номера (добавление суффикса `@c.us` при вводе номера без него).
4. **`sendFileByUrl`** (`POST {{apiUrl}}/waInstance{{idInstance}}/sendFileByUrl/{{apiTokenInstance}}`)
   - Отправляет файл (изображение, документ, медиа) по прямой ссылке.
   - Автоматически извлекает имя файла (`fileName`) из переданного URL.
   - Включает готовые примеры файлов (PNG логотип, JPG фото, PDF документ) для тестирования в 1 клик.
5. **`sendFileByUpload`** (`POST {{mediaUrl}}/waInstance{{idInstance}}/sendFileByUpload/{{apiTokenInstance}}`)
   - Позволяет выбрать любой файл (картинка, PDF, видео, документ) прямо на сайте с устройства или через Drag & Drop.
   - Наглядный предпросмотр выбранного файла с миниатюрой, именем и размером.
   - Поддержка опциональной текстовой подписи (`caption`) к файлу.
6. **Отображение ответа («Ответ:»)**:
   - Ответ метода выводится в отдельное поле только для чтения (`readonly`).
   - Форматированный вывод JSON с отступами и подсветкой статуса (`200 OK`, `401 Unauthorized` и т.д.).
   - Отображение времени выполнения запроса (latency в мс).
   - Кнопка быстрого копирования ответа в буфер обмена.

## 🎨 Дизайн и соответствие макету

- **Двухколоночный макет**: в точности повторяет структуру из технического задания:
  - **Слева**: параметры подключения (`idInstance`, `ApiTokenInstance`), быстрые кнопки `getSettings` и `getStateInstance`, блоки для `sendMessage` и `sendFileByUrl`.
  - **Справа**: метка `Ответ:` и большое окно вывода ответа сервера.
  - **Оформление**: стилизовано под окно браузера с тремя цветными кнопками управления и фирменным стилем GREEN-API.
- **Удобство использования**:
  - Сохранение `idInstance` и `ApiTokenInstance` в `localStorage` (не нужно вводить заново при перезагрузке).
  - Кнопка скрытия/отображения токена авторизации (`eye toggle`).
  - Индикация загрузки (спиннер на кнопках во время выполнения запроса).
  - Всплывающие уведомления (Toast) об успехе или ошибке ввода.
  - Раскрывающийся блок для указания кастомного `apiUrl` (по умолчанию `https://api.green-api.com`).

## 🛠 Быстрый запуск локально

Проект не требует сборщиков и работает прямо в браузере.

### Вариант 1. Запуск через локальный сервер (Node.js)
```bash
node server.js
```
Откройте в браузере: [http://localhost:3000](http://localhost:3000)

### Вариант 2. Открытие напрямую
Просто откройте файл `index.html` в любом браузере:
```bash
start index.html
```

## 📋 Инструкция по тестированию

1. Зарегистрируйтесь в личном кабинете [GREEN-API Console](https://console.green-api.com/).
2. Создайте новый инстанс на бесплатном тарифе разработчика.
3. Отсканируйте QR-код в приложении WhatsApp на телефоне для привязки номера к инстансу.
4. Скопируйте из личного кабинета:
   - `idInstance`
   - `ApiTokenInstance`
5. Перейдите на опубликованную страницу:
   - Вставьте параметры в соответствующие поля ввода.
   - Нажмите **`getStateInstance`** — в поле «Ответ:» появится статус авторизации (например, `"stateInstance": "authorized"`).
   - Нажмите **`getSettings`** — отобразятся текущие настройки инстанса.
   - В блоке **`sendMessage`** укажите номер получателя (в формате `77761985879`) и текст сообщения, затем нажмите кнопку отправки.
   - В блоке **`sendFileByUrl`** укажите номер получателя и прямую ссылку на изображение (например, `https://green-api.com/img/logo.png`), затем нажмите кнопку отправки.
